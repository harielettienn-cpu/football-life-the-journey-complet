# FOOTBALL LIFE — THE JOURNEY

Jeu de simulation de carrière de footballeur, construit avec Next.js 14 et React.

## Lancer en local
```bash
npm install
npm run dev
```
Puis ouvrir http://localhost:3000

## Déployer sur Vercel
1. Envoyer tous les fichiers de ce dossier à la racine d'un dépôt GitHub.
2. Importer le dépôt dans Vercel.
3. Framework : Next.js ; commande de build : `npm run build`.
4. Déployer.

## Fonctionnalités
- Création de joueur, choix du poste, pied fort, pays et double nationalité.
- Carrière saison après saison, calendrier de matchs et rencontres jouables par actions.
- Plusieurs championnats fictifs inspirés des grandes ligues, classements et résultats simulés.
- Entraînement et évolution des attributs, fatigue, moral, blessures et forme.
- Contrats, salaires, transferts simplifiés, finances et réputation.
- Convocations internationales simulées, trophées, historique et actualités.
- Sauvegarde automatique dans le navigateur (localStorage).

## Limites honnêtes
C'est un jeu solo autonome avec univers et résultats simulés. Il ne contient pas les licences officielles des clubs/joueurs, ni de données sportives en direct, ni de comptes en ligne ou sauvegarde cloud. Les sauvegardes sont liées au navigateur et à l'appareil utilisés.
